- Handler-specific behavior is implemented via the TransactionProcessor + handler classes.
- **Traceability gap (2026-10-21):** FR-PROC-013 (Add Customer / Add Vendor master data
  assist) is defined in [Functional Requirements.md](Functional%20Requirements.md) but had no
  row in this matrix, and no UAT case covers it. The row above records the gap explicitly
  rather than leaving the requirement silently untraced. Close it by authoring
  `UAT-PROC-013` (Add Customer action creates an FA debtor and links it; Add Vendor action
  creates an FA supplier) and adding the corresponding test IDs.
