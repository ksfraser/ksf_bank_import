# PMBOK / Project Management Documentation (New Convention)

## Naming: PM-XXX-YYY-ZZZ
- PM-001-Scope: Scope definition / WBS
- PM-002-Schedule: Timeline / Milestones
- PM-003-Cost: Budget / Resource allocation
- PM-004-Quality: QA / Testing plans
- PM-005-Risk: Risk assessment / Mitigation
- PM-006-Procurement: Vendor / Contract management
- PM-007-Comm: Communication / Stakeholder
