# Requirements Naming Convention (Updated)

## Categories
- UC-XXX: Use Case (major) - YYY (sub) - ZZZ (details)
- BR-XXX: Business Requirement (major) - YYY (sub if needed)
- FR-XXX / FR-XXX-YYY / FR-XXX-YYY-ZZZ: Functional Requirement (matches BR)
- ARCH-XXX: Architecture Requirement (matches BR design target)
- UAT-XXX / UC-XXX: User Acceptance / Use Case test

## Module Subdirectories
For larger modules, create:
- docs/BusinessRequirements/
- docs/FunctionalRequirements/
- docs/Architecture/
- docs/TestCases/
- docs/UAT/
